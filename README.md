# Hangman Game

## Description

This is a text-based Hangman game made with Python. The program selects a random word from five predefined words. The player guesses one letter at a time and has six incorrect guesses before the game ends.

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```powershell
python main.py
```

## Concepts Used

- `random` module
- Lists
- While loops
- For loops
- If-else conditions
- User input and output
